# 05 — Data

**This server has no database, and must not get one.**

| Data | Where it lives |
|---|---|
| Room state (players, pawns, dice, turn, chat) | memory, for the life of the room |
| Dice-AI and timing config | memory, defaults from code; reset on restart (as today) |
| Logs | stdout + the in-memory log buffer the dashboard reads |
| Users, profiles, friends, invites, results, leaderboard | **`game-backend`** |

Consequences:

- A restart drops running rooms (true today). Deploy at a quiet hour.
- Dashboard config changes are lost on restart. If that matters later, they belong in
  `game-backend` (remote config), not in a database here.
- More than one instance needs Colyseus' presence/driver (Redis) for cross-process rooms —
  **not needed now**; one instance is enough at today's load.
